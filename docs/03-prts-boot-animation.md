# PRTS 引导序列规格

## 设计依据

版式取自《明日方舟》终端 / 档案体系的梳理 [PRTS Design](https://mooncellwiki.github.io/prts-design/)
（MooncellWiki，CC BY-NC-SA 4.0）：黑白灰承载信息、直角与发丝线、编号与拉丁大写作装饰、菱形是源石母题、
强调用明度反转而不是彩色。

按「主机终端」的方向做了三点收敛：

1. **只用黑白灰**。早期的青蓝和鎏金都是装饰性用色，已全部移除；颜色只作为状态存在（告警、故障）。
   层级靠明度分级与 `ESC[7m` 反转表达，和主机控制台一致。
2. **只用设定里存在的名字和实测数据**。页眉是 `PRTS` / `RHODES ISLAND`，第二行是会话时间与序号；
   正文是七个模块的实测值。不额外造词、不加说明性副标题。
3. **日志带时间戳**。七行自检按真实打印时刻编号（`HH:MM:SS.mmm`），读起来就是一台机器在写日志。

不使用任何游戏素材，菱形由网格算法生成。

## 配色

| 角色 | 值 | 用途 |
| --- | --- | --- |
| background | `#000000` | 画布 |
| rule | `#2E2E2E` | 分隔细线 |
| primary | `#F0F0F0` | 数值、结论 |
| secondary | `#BFBFBF` | 条形、菱形轮廓、状态、序号 |
| muted | `#8A8A8A` | 标签、会话行、接入记录 |
| subtle | `#5A5A5A` | 时间戳、括号、进度轨道、耗时 |
| warn | `#C9A227` | 仅告警状态 |
| danger | `#C0392B` | 仅故障状态 |

颜色不单独承载语义：`[ OK ]`、`[WARN]`、`[FAIL]` 的文字本身说明状态，颜色是第二层提示。

## 紧凑版式（19 行）

终端高度 < 27 行或宽度 < 62 列时启用，菱形换成单行标识：

```
▌ PRTS                                                    RHODES ISLAND  ◤
▌ SESSION 2026-11-13 19:00:23                                       NO. 36
──────────────────────────────────────────────────────────────────────────

 ◆ PRTS ◆
──────────────────────────────────────────────────────────────────────────
19:00:30.101  KERNEL    Linux 6.18.50+rpt-rpi-v8                    [ OK ]
 ...
```

## 菱形涟漪

徽标不是直接画出来的，而是从中心「涨」出来的：

| 帧 | 内容 | 颜色 | 停留 |
| --- | --- | --- | --- |
| 1 | 3 行菱形 | secondary | 60 ms |
| 2 | 5 行菱形 | muted | 60 ms |
| 3 | 7 行菱形 | subtle | 60 ms |
| 4 | 9 行菱形（正式徽标） | secondary | 逐行 26 ms |

三帧由亮到暗，读起来像一圈扩散后淡出的涟漪，最后落到实线上；随后字标 `P  R  T  S` 逐字打出。

## 时序

| 阶段 | 动作 | 默认耗时 |
| --- | --- | --- |
| 1 | 清屏、隐藏光标、页眉与细线 | ~60 ms |
| 2 | 菱形涟漪 3 帧 | ~180 ms |
| 3 | 徽标逐行落下 + 字标打出 | ~320 ms |
| 4 | 七行带时间戳的自检，每行一次黑白反转 | ~2.4 s |
| 5 | 进度条 14 帧填充 | ~340 ms |
| 6 | 结论、接入记录、状态行 | ~500 ms |
| 合计 | | 约 3.5–3.8 s |

节奏由 `[general]` 的 `char_delay_ms`、`frame_delay_ms`、`check_delay_ms` 控制。

## 黑白反转

方舟用明度反转而不是彩色标记当前项。每行自检会：

1. 正常绘制（时间戳灰、标签灰、值白、状态浅灰 / 琥珀 / 红）
2. 整行反转为黑底白字（`ESC[7m`）停留 55 ms
3. 擦除重绘为正常样式

由 `[general] flash_frames` 控制，设为 0 可关闭。

## 文案

| 位置 | 文案 |
| --- | --- |
| 页眉 | `PRTS` / `RHODES ISLAND` / `SESSION <时间>` / `NO. <序号>` |
| 结论 | `全部模块响应正常` · `系统正常，存在告警` · `检测到系统故障` |
| 接入记录 | `接入记录  <操作员> · 第 N 次 · 上次接入 <时间>` |

规则：只写设定里存在的名字和实测数据，不写说明性副标题、不写欢迎语、不写剧情内容。

## 自适应与可访问性

| 场景 | 行为 |
| --- | --- |
| 非 TTY | 不播放动画；`--check` 输出纯文本报告 |
| `PRTS_SKIP_BOOT=1` | 立即退出，登录钩子也会跳过 |
| `NO_COLOR=1` / `TERM=dumb` | 保留版式，去掉全部 ANSI 颜色 |
| 终端过窄 | 紧凑版式；宽度下限 40 列 |
| 自检失败 | 退出码 1（登录钩子忽略退出码，不影响 shell） |

## 状态判定

| 结论 | 条件 |
| --- | --- |
| FAIL | CPU ≥ 80 °C；内存可用 < 8%；磁盘可用 < 5% |
| WARN | CPU ≥ 70 °C；内存可用 < 15%；磁盘可用 < 15%；无 IPv4；sshd 不可见 |
| OK | 其余情况 |
