# PRTS 引导序列规格

## 设计依据

视觉语言取自《明日方舟》的终端 / 档案体系，并参考了社区整理的设计规范
[PRTS Design](https://mooncellwiki.github.io/prts-design/)（MooncellWiki，CC BY-NC-SA 4.0）：
黑白灰承载信息、青色只用于选中、直角与 1px 细线、编号与拉丁大写作装饰、菱形是「源石」母题。

终端形态另有两处调整，来自「主机系统」而不是「驾驶舱」的定位：

1. **金代替青**。拉特兰那台主机的鎏金质感比青蓝更贴合「古老、权威、恒温」的主机气质，
   也比青蓝在黑底上更耐看。金色只出现在左侧色条、右上角标、核心菱形、进度条与告警，
   其余全部是白与灰。
2. **语气像主机**。日志不是玩家面板的提示语，而是带档案口吻的记录：
   `接入记录：seven · 第 12 次。上次接入 …。PRTS 已就绪，等待指令。`

不使用任何游戏素材，所有图形由字符网格生成。

## 配色（终端主题）

| 角色 | 值 | 用途 |
| --- | --- | --- |
| background | `#000000` | 画布 |
| rule | `#333333` | 分隔细线 |
| primary | `#F2F2F2` | 数值、被强调的正文 |
| secondary | `#C6C6C6` | 菱形轮廓、状态标签、序号 |
| muted | `#8A8A8A` | 标签、说明、接入记录 |
| subtle | `#5C5C5C` | 序号、括号、进度轨道、耗时 |
| accent | `#D9A441` | 左色条、角标、核心菱形、进度条、告警 |
| accent_bright | `#F0C674` | 预留的高亮金 |
| danger | `#D4483B` | 仅用于检测失败 |

规则：颜色不单独承载语义。`[ OK ]` / `[WARN]` / `[FAIL]` 的文字本身就说明了状态，
颜色只是第二层提示（这也是一条无障碍要求）。

```
──────────────────────────────────────────────────────────────────────────
 01   KERNEL    Linux 6.18.50+rpt-rpi-v8                            [ OK ]
 02   HOST      PRTS · Pi 3 Model B Rev 1.2                         [ OK ]
 03   CORE      4 threads · 1200 MHz · 45.6 C                       [ OK ]
 04   MEMORY    738 MiB free / 905 MiB                              [ OK ]
 05   ARCHIVE   10.2 GiB free / 13.8 GiB                            [ OK ]
 06   LINK      wlan0 · 192.168.210.239                             [ OK ]
 07   ACCESS    sshd online · 1 session                             [ OK ]

 BOOT  █████████████████████████████████████████████████████  100%  03.60s
 ◆ 全部模块响应正常   ALL MODULES NOMINAL                            7 / 7
 接入记录：seven · 第 23 次。上次接入 2026-11-13 18:31:51。PRTS 已就绪，等待指令。
 ▸ CPU 45.6 C   MEM 19%   DISK 26%   LOAD 1.15   UP 01:35
```

版式要点：

- 左侧 `▌` 是「色条 + 细框」里的色条，只出现在页眉两行，不铺满全屏
- 右上 `◤` 是角标三角
- 菱形用 `╱ ╲` 逐行步进 2 格绘制（终端单元格约 1:2，这样斜率才像 45°）
- 编号 `01–07`、拉丁大写标签、右侧状态值构成「档案表格」的阅读节奏

## 紧凑版式（18 行）

终端高度 < 27 行或宽度 < 62 列时启用，菱形换成单行标识：

```
▌ PRTS                                                    RHODES ISLAND  ◤
▌ PRIMARY RHODES ISLAND TERMINAL SYSTEM                             NO. 32
──────────────────────────────────────────────────────────────────────────

 ◆ PRTS ◆   原生罗德岛终端服务  ·  访问权限已确认
──────────────────────────────────────────────────────────────────────────
 01   KERNEL    Linux 6.18.50+rpt-rpi-v8                            [ OK ]
 ...
```

## 时序

| 阶段 | 动作 | 默认耗时 |
| --- | --- | --- |
| 1 | 清屏、隐藏光标、页眉与细线 | ~60 ms |
| 2 | 菱形逐行落下（9 行，26 ms/行） | ~240 ms |
| 3 | 字标 `P  R  T  S` 逐字打出 | ~90 ms |
| 4 | 七条自检：编号/标签即时出现，值逐字打出，随后整行黑白反转一帧 | ~2.4 s |
| 5 | 进度条 14 帧填充 | ~350 ms |
| 6 | 结论、接入记录、状态行 | ~500 ms |
| 合计 | | 约 3.6–3.8 s |

节奏由 `[general]` 的 `char_delay_ms`、`frame_delay_ms`、`check_delay_ms` 控制。

## 黑白反转

方舟用「明度反转」而不是彩色表示当前项。自检时每一行会：

1. 正常绘制（编号灰、标签灰、值白、状态浅灰/金/红）
2. 整行反转为黑底白字（`ESC[7m`）停留 55 ms
3. 擦除重绘为正常样式

由 `[general] flash_frames` 控制，设为 0 可关闭。

## 文案语气

| 位置 | 文案 |
| --- | --- |
| 页眉副标 | `PRIMARY RHODES ISLAND TERMINAL SYSTEM` |
| 菱形下方 | `原生罗德岛终端服务  ·  访问权限已确认` |
| 结论 | `全部模块响应正常` / `系统正常，存在告警` / `检测到系统故障` |
| 接入记录 | `接入记录：<操作员> · 第 N 次。上次接入 <时间>。PRTS 已就绪，等待指令。` |

原则：陈述事实、不寒暄、不使用感叹号；用「记录 / 接入 / 校验 / 就绪」这类档案词而不是「欢迎使用」。

## 自适应与可访问性

| 场景 | 行为 |
| --- | --- |
| 非 TTY | 不播放动画；`--check` 输出纯文本报告 |
| `PRTS_SKIP_BOOT=1` | 立即退出，登录钩子也会跳过 |
| `NO_COLOR=1` / `TERM=dumb` | 保留版式，去掉全部 ANSI 颜色 |
| 终端过窄 | 紧凑版式；宽度下限 40 列 |
| 自检失败 | 退出码 1（登录钩子忽略退出码，不影响 shell） |

## 状态判定

| 结论 | 条件 |
| --- | --- |
| FAIL | CPU ≥ 80 °C；内存可用 < 8%；磁盘可用 < 5% |
| WARN | CPU ≥ 70 °C；内存可用 < 15%；磁盘可用 < 15%；无 IPv4；sshd 不可见 |
| OK | 其余情况 |
