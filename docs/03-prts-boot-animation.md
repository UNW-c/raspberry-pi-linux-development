# PRTS 引导序列规格

## 视觉语言

参考《明日方舟》PRTS 终端：黑色底、直角面板、极细边框、青色强调、菱形身份标、扫描线。
本项目只借用视觉语言，不使用任何游戏素材，所有图形由字符网格绘制。

| 角色 | 颜色 | 用途 |
| --- | --- | --- |
| frame | `#11AFCF` | 面板边框、扫描高亮 |
| frame_dim | `#0C5463` | 次级线条、点引导线、时间戳 |
| primary | `#C8D2D6` | 正文数值 |
| muted | `#67757B` | 标签、提示语 |
| accent / accent_bright | `#11AFCF` / `#8FE9FA` | 徽标、扫描峰值 |
| ok / warn / error | `#6FBF9B` / `#D9A441` / `#B4433C` | 自检结论 |

## 时序

| 阶段 | 动作 | 默认耗时 |
| --- | --- | --- |
| 1 | 清屏、隐藏光标、绘制面板 | ~50 ms |
| 2 | 徽标逐行下落（7 行 + 5 行字标，32 ms/行） | ~390 ms |
| 3 | 扫描线横向扫过（`scan_sweeps` 次，30 ms/帧） | ~600 ms |
| 4 | 7 条自检逐字输出 + 结论浮现 | ~1.6 s |
| 5 | 进度条 12 帧填充 | ~360 ms |
| 6 | 结论逐字、欢迎语、状态栏 | ~400 ms |
| 合计 | | 约 3.4 s |

节奏由 `[general]` 的 `char_delay_ms`、`frame_delay_ms`、`check_delay_ms` 控制。

## 扫描线

对每个扫描帧：把光标上移 12 行，逐行重绘徽标与字标，字符满足
`|col - sweepColumn| <= 2` 时使用 `accent_bright` 加粗，其余按行渐变
（顶部 `accent_bright` → 底部 `accent`）。扫描列从 `-4` 走到 `artWidth + 4`，步长 3。

## 自检行格式

```
  [累计秒]  标签(10)  ....(12)  值(可变)  [结论]
```

- 累计秒：自序列开始计时，六位 `%06.3f`，超过 99.999 截断
- 标签：不足 10 列补空格（按终端显示宽度，不是字节数）
- 值：按可用列数截断，超出部分以 `..` 结尾
- 结论：`[ OK ]` / `[WARN]` / `[FAIL]`

## 自适应与可访问性

| 场景 | 行为 |
| --- | --- |
| 非 TTY（管道、scp、`ssh host cmd`） | 不播放动画；`--check` 输出纯文本报告 |
| `PRTS_SKIP_BOOT=1` | 立即退出，登录钩子也会跳过 |
| `NO_COLOR=1` 或 `TERM=dumb` | 保留版式，去掉全部 ANSI 颜色 |
| 终端过窄（< 78 列） | 紧凑版式；宽度下限 30 列 |
| 自检失败 | 退出码 1（登录钩子忽略退出码，不影响 shell） |

## 状态判定

| 结论 | 条件 |
| --- | --- |
| FAIL | CPU ≥ 80 °C；内存可用 < 8%；磁盘可用 < 5%；任一探针异常 |
| WARN | CPU ≥ 70 °C；内存可用 < 15%；磁盘可用 < 15%；无 IPv4；sshd 不可见 |
| OK | 其余情况 |
